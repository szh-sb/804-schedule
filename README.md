# 课表快选

这是一个基于 2026 年秋季课表数据的轻量选课与排课原型。

## 已实现

- 按课程名、课程号、教师搜索，按学科和课程性质筛选
- 支持从 Excel/表格整列粘贴课号，自动按行拆分、去重并批量加入
- 一键加入/移出课程，自动计算学分、课时和时间冲突
- 周视图与列表视图，按天和节次查看安排
- 课程详情弹窗（周次、地点、教师、课程属性）
- 本地保存选课结果、生成可分享链接、打印课表
- 响应式布局，手机和电脑都可使用

## 面向同学共用的落地方案

第一版先用静态站点即可部署到学校服务器、GitHub Pages 或 Vercel，课程数据放在 `data/courses.json`，访问速度快且成本低。多人协作版建议增加一个很薄的后端：

1. 用户用学号/微信登录，选课结果存入 SQLite/Postgres。
2. 分享链接改成短码，支持“只读分享”和“共同编辑”。
3. 管理员可上传新的 Excel，服务端统一解析成 JSON，并保留学期版本。
4. 冲突检查放在前端即时执行，提交时后端再校验一次，避免脏数据。

## 本地运行

在当前目录启动任意静态文件服务器，然后打开 `index.html` 即可。例如使用 VS Code Live Server，或 `python -m http.server 8080` 后访问 `http://localhost:8080`。
